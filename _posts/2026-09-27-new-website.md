The group website has moved from Google Sites to this page, which is built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme and hosted on GitHub Pages.

The main practical change is that the [publications](/publications/) page no longer needs to be edited by hand: a script queries arXiv every night and regenerates the list, so new preprints and journal references appear on their own.

This *Notes* section is for occasional research notes, lecture notes, and announcements. Posts are plain Markdown files with support for $\LaTeX$ math, for example $\rho \mapsto \mathcal{N}(\rho)$, code blocks, and figures.
